# 🤖 CodeAlpha FAQ Chatbot

An AI-powered FAQ Chatbot developed using **Python Flask and NLP techniques**.  
The chatbot understands user queries and provides relevant answers using a machine learning-based FAQ matching system.

---

## 🌟 Features

✅ Interactive chatbot interface  
✅ NLP-based question matching  
✅ TF-IDF similarity algorithm  
✅ FAQ knowledge base using JSON  
✅ Voice input support 🎤  
✅ Chat history storage  
✅ Flask web application  
✅ Simple and responsive UI  

---

# ⚙️ Installation and Setup

## 1. Clone Repository

```bash
git clone https://github.com/moksharegonda03-arch/CodeAlpha-FAQ-chatbot.git
```

---

## 2. Navigate to Project Folder

```bash
cd CodeAlpha-FAQ-chatbot
```

---

## 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

Start the Flask server:

```bash
python app.py
```

The chatbot will run at:

```
http://127.0.0.1:5000
```

Open this URL in your browser.

---

# 🧠 Working Process

1. User enters a question.
2. The chatbot processes the input using NLP.
3. TF-IDF converts text into numerical vectors.
4. Similarity matching finds the closest FAQ.
5. The chatbot returns the best answer.
6. Chat history is saved automatically.
